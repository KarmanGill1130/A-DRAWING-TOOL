# 🎨 Drawing Tool Project

## 📌 Project Overview

This project is a **Drawing Tool** developed by a team of three members. It provides users with an interactive canvas to draw, fill colors, and use shape tools. The application is user-friendly and designed to support basic digital drawing and coloring tasks.

## 🧰 Features

- ✏️ **Freehand Drawing Tool**  
  Allows the user to draw freely on the canvas using a virtual pencil.

- 🟥 **Shape Tools**  
  Users can draw predefined shapes such as:
  - Rectangle
  - Circle
  - Line

- 🎨 **Color Picker and Fill Tool**  
  - Select any color to draw or fill.
  - Bucket tool to fill enclosed areas with the selected color.

- 💡 **Undo / Clear Canvas (Optional Feature)**  
  - Clear the canvas for a fresh start.
  - Undo the last action (if implemented).
